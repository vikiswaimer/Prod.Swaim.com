# Портрет и ниши — Tool Map

## Портрет пользователей (стабильный каркас)

**Кто:** фаундеры и предприниматели (соло / микрокоманда), чаще RU или RU+global digital.

| Признак | Как выглядит |
|---------|----------------|
| Роль | Основатель продукта, микро-SaaS, услуги, инфобизнес, агентство 1–5 чел. |
| Работа | Сам собирает стек: канал, лендинг, учёт, оплата, контент, ИИ |
| Боль | Тонет в «топ-N инструментов», нет **карты связок** под свой сценарий |
| Готовность платить | Небольшая сумма за готовый плейбук «что с чем и в каком порядке» |

Это **не ниша** — это портрет. Ниши внутри портрета **тестируем**.

## Ниши = гипотезы (добавлять / убирать по тестам)

Каждая ниша — эксперимент: map + CTA + трафик → сигнал → keep / iterate / kill.

| Правило | Как |
|---------|-----|
| WIP ниш | ≤1–2 активных map в разработке; остальные в бэклоге |
| Сигнал keep | `map_viewed` + клики + `paid_cta` / оплаты |
| Сигнал kill / пауза | 0 интерес после 3 честных тестах канала **или** Mom Test «не та боль» |
| Кто решает | PO предлагает keep/kill по данным; основатель ок на kill крупной ставки |
| Портрет | не меняем каждый цикл; меняем **ниши и стеки** |
