# Отчёт: группа Бизнес (foundation)

Дата: 2026-07-28 · Ветка: `cursor/business-foundation-5937` · Issue: **#24**

## Цель

Перестроить группу **Бизнес** под ясный foundation: сегмент через поведение и сигнал, MVP как полезный срез, оффер с границами, альтернативы через outcomes, must-have до ценного среза.

## Анализ: блоки

| Блок | Было | Решение |
|------|------|---------|
| Твой продукт | Очищен в A; без MVP/outcome | Outcome, гипотеза ценности, минимальный срез, успех, главный риск; smoke-test ≠ MVP |
| Клиенты | Age/Gender + EN journey | Портрет сегмента: контекст, боль, workaround, commitments; демография вторична |
| Продукты / услуги | Ответы автора в шаблоне | Blank + структура оффера; прайс автора → examples |
| Конкуренты | «плюшки» + EN UVP | Прямые / косвенные / status quo; за что платят; где проигрываем |
| Стратегия маркетинга | Уже ок (C) | Связка с Клиентами / Твой продукт |
| Необходимые шаги | Логотип/баннеры как старт | Категории: до ценного среза / nice / не сейчас |

Опора: **Mom Test** (клиенты, без названия книги в UI), **Olsen + владелец** (MVP = ценный срез), **Cagan** (outcomes, риски valuable/usable/feasible/viable).

## Что изменилось

### Хабы

- `Клиенты`, `Твой продукт`, `Продукты Услуги`, `Конкуренты`, `Необходимые шаги` — мини-гайды.
- `Маркетинг` (стратегия) — точечная связка с сегментом и срезом.

### CSV / схемы

- Портрет: Segment context, Pain, Workaround, Tried before, Commitment signal, Evidence status (+ демография вторично).
- Оффер: Segment, Problem/outcome, Scope in/out, Price, Type, Evidence, Status.
- Конкуренты: Type, Outcome, Already pay with, Why switch, Where we lose, Strengths/Weaknesses.
- Must-have: Category, Risk closed, Cost, Comment, Status.
- Таблица раздела `Бизнес--d4f8f42c.csv` — новые описания.

### Демо и examples

- Саша / Notion / Miro — демо формата.
- Авторский прайс и старые ответы → `examples/продукты-услуги-пример.md` и др.
- Новые: `клиенты-портрет-пример.md`, `конкуренты-пример.md`, `необходимые-шаги-пример.md`; дополнен `твой-продукт-пример.md`.

### Навигация

- `00-index.md` — порядок foundation + короткие пояснения.
- `INDEX.md` — RU-подписи, «Портрет сегмента», архив оффера.
- Трек «Старт» — усилены формулировки клиентов / must-have.

### Не трогали

- Feedback CSV / каналы (#19 на отдельной ветке).
- `Брэнд/Позиционирование` (вне группы; согласовать позже при желании).
- Имя файла `Протрет пользователя--*` (hash Notion) — RU-подпись в UI.
