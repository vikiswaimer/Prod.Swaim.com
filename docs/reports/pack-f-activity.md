# Отчёт: группа Активность (Lean + аналитика)

Дата: 2026-07-26 · Ветка: `cursor/activity-lean-analytics-6e5e` · Issue: **#22**

## Цель

Перестроить группу **Активность** под Build → Measure → Learn: банк идей с гипотезами, рекомендация вести исполнение в Linear / GitHub Issues, новый блок **Аналитика**, сжатие шума (заметки опциональны).

## Анализ: блоки ↔ Lean Startup

| Блок | Было | Lean-роль | Решение |
|------|------|-----------|---------|
| Цели | SMART + difficulty, vanity-пример «500 email» | Direction / North Star | Outcomes, baseline→target, leading indicator, критерий решения |
| Идеи | Score Trust/Ease/Impact, мало гипотезы | Backlog обучения | **Банк идей**: гипотеза, статус, сигнал, вывод, ссылка наружу |
| Задачи | Почти пустая база | Build / WIP | Типы + WIP; предпочтение Linear/GitHub для AI-работы |
| — | Не было Measure | Measure | Новый хаб **Аналитика** |
| Рефлексия | «Что было хорошо/плохо» | Learn | BML + сила сигнала + pivot/persevere |
| Заметки | Общий блокнот | Шум / дубль банка | Депрекейт: сырое → в идеи |
| Календарь | Встречи + шум `лоловп` | Таймбокс (часть H) | Лёгкий фрейм событий обучения |

Опора: **Ries** (цикл, WIP, инновационный учёт), **Cagan** (outcomes). Mom Test — через отсылки к Интервью/Отзывам, без дублирования чеклистов.
