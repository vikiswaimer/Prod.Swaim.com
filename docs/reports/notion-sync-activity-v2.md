# Notion sync — Активность v2 (сжатие до 4 поверхностей)

Дата: 2026-07-26 · Issue #22 · Скрипт: `scripts/notion_sync_activity_v2.py`

## Решение

Вместо 7 блоков с вложенными базами — **4 плоские поверхности**:

| Страница | Nested DB |
|----------|-----------|
| Цели | убрана |
| Гипотезы | **одна** рабочая таблица сохранена |
| Аналитика | нет |
| Обзор недели (бывш. Рефлексия) | убрана |

**Архивированы** в DB Активность: Задачи, Заметки, Календарь.
