# Отчёт: каналы обратной связи (issue #19)

Дата: 2026-07-24 · Ветка: `cursor/feedback-channels-b251`

## Цель

Ответить в шаблоне: **где** и **как** лучше принимать обратную связь от клиентов — с картой каналов по цели и связкой Отзывы ↔ Интервью.

## Что сделано

### Отзывы
- Карта каналов: цель → лучший канал → слабость канала.
- Правило соло: 1 канал обучения (интервью) + 1 момент «после ценности»; витрина отдельно.
- Когда просить; короткий скрипт запроса; усилен чеклист.
- CSV Feedback: `Channel`, `Segment`, `Signal`, `Quote`, `Publish` (+ рейтинг опционально).
- Демо Alice — поле «Канал».

### Интервью
- Блок доведён до ветки от `main` (раньше остался только на `cursor/other-mini-guides-7cdb` после PR #15).
- Хаб + база «Заметки интервью» + демо.

### Навигация
- `00-index`, `INDEX`, CSV Other (+ all), треки Старт / Развитие, `docs/glossary.md`.

## Методология
- **Mom Test / Fitzpatrick** — прошлое поведение, сильный vs слабый; в пользовательском тексте без названия книги.
- **Cagan** — канал выбирается под outcome (обучение / витрина / приоритеты).
- **Ries** — ритуал сбора сигнала кормит learn-цикл; не путать с delivery «накопить пятёрки».
