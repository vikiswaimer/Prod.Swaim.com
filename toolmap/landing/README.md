# Landing — Tool Map

Посадочные и схемы для портрета **фаундеры / предприниматели**.

## Открыть

Из `map/`:

```bash
npx --yes serve -p 5173
```

- Хаб вариантов: http://localhost:5173/landing/
- Public default: http://localhost:5173/
- Живая map: http://localhost:5173/map.html
- A Cartograph: `/landing/a-cartograph.html`
- B Foundry: `/landing/b-foundry.html`
- C Blueprint: `/landing/c-blueprint.html`
- Схемы: `/landing/schemes.html`
