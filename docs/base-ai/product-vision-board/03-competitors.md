# Competitors & Alternatives

**Status quo, не только «похожие шаблоны».**

| Альтернатива | Что отбирает | Слабое место |
|--------------|--------------|--------------|
| Пустой Notion / all-in-one kit | «Быстро начать» | Сборка дольше продукта |
| Notion на заказ (фриланс) | Кастом | Нет маршрута → заброс |
| ChatGPT / Cursor без vault | Скорость текста | Нет SoT, план на 20 пунктов |
| Курсы и закладки | Мотивация | Нет операционки |
| PM/CRM SaaS | Зрелые процессы | Overkill для соло |

## Наш угол

Готовый **маршрут + методология + RU digital product**, не retail/e-com демо.
