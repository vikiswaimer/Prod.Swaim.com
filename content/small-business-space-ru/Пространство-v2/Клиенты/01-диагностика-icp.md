# 01. Диагностика ICP — кто покупает на самом деле

## 1. Боль

«Мы вроде знаем аудиторию, но продаём всем — и почти никому».  
Портреты красивые, а деньги приходят от другого сегмента (или не приходят).

## 2. Симптомы — это про вас, если

- в описании клиента слова «все, кто…» / «малый бизнес в целом»
- лучшие клиенты сильно отличаются от «идеального портрета» на сайте
- много демо — мало сделок; после оплаты люди просят не то, что вы продавали
- не можете за 20 секунд сказать, кого вы **не** берёте

## 3. Алгоритм (45–90 минут)

1. Выпишите **последние 5–10 платящих** (или самых близких к оплате).  
2. По каждому: триггер покупки, что болело, бюджет, кто решал, что почти сорвало сделку.  
3. Найдите пересечения (≥3 совпадения) — это черновик ICP.  
4. Отдельно список **анти-ICP** (с кем выгораете / кто не платит).  
5. Сформулируйте ICP в 6 полях ниже.  
6. Проверка: можете ли отказать «почти подходящему» за 1 фразу?

## 4. Шаблон ICP (6 полей)

| Поле | Ваш ответ |
|------|-----------|
| Кто (роль + контекст) | |
| Какая работа/боль (их словами) | |
| Триггер «пора решать» | |
| Бюджет / готовность платить | |
| Как уже пытались решить | |
| Кого НЕ берём | |

## 5. Пример — Studio North

| Поле | Ответ |
|------|--------|
| Кто | Фаундер digital-продукта, 1–3 человека в команде, уже есть черновик продукта |
| Боль | «Тонну задач веду в голове и Notion-хаосе, продажи случайные» |
| Триггер | Первый платящий клиент или предзапуск через 4–6 недель |
| Бюджет | 120–200k ₽ на сборку OS + запуск, или 25k ₽/мес |
| Уже пробовали | Пустой Notion, ChatGPT-промпты, фриланс «сделайте сайт» |
| НЕ берём | «Сделайте нам всё под ключ без участия», корпорации с тендером, чистый e‑com без digital-продукта |

**Анти-ICP (коротко):** новичок «хочу бизнес с нуля без темы»; клиент, которому нужен только дизайн лендинга.

## 6. Визуал — матрица пригодности

Оцените сегмент 1–5 по осям. Берите тех, кто ≥4 по боли и деньгам.

```text
                 Деньги / готовность платить →
                 низкая              высокая
              ┌────────────┬────────────┐
 боль/срочн.  │     A      │     B      │
 высокая      │  держать   │   ЯДРО ★   │
              │   редко    │            │
              ├────────────┼────────────┤
 боль низкая  │     D      │     C      │
              │    стоп    │ долго греть│
              └────────────┴────────────┘
```

- **B (ядро)** — основной фокус продаж  
- **C** — nurture, не приоритет этой недели  
- **A** — только если почти бесплатно по времени  
- **D** — стоп  

Studio North: сегмент «фаундер с датой запуска» = B; «хочу когда-нибудь» = D/C.

## 7. Метрика успеха

За 2 недели:

- есть 1 страница ICP + анти-ICP  
- ≥50% новых лидов можно сразу пометить: ядро / греть / стоп  
- хотя бы **1 осознанный отказ** от не-ICP (это здоровый сигнал)

## 8. Антипаттерн

Не рисуйте 5 персон «на будущее». Одна узкая ICP лучше пяти вымышленных.  
Демография без поведения («мужчины 30–40») — почти бесполезна.
