# Конкуренты — Tool Map

## Альтернативы

1. Product Hunt / альтернативы.app — каталоги без нишевой map-связки.  
2. YouTube «лучший стек 2026» — разрозненно, устаревает.  
3. Notion-таблицы «100 инструментов» — списки без графа связок.  
4. Платные курсы «автоматизация» — дорого и долго.

Визуальная **map** + рёбра связок + дешёвый подробный слой, а не энциклопедия.
