# Lean-эксперименты продвижения Prod.Swaim (SWA-6)

**Роль:** Growth Lead · **Статус:** готово к запуску (выбрать **один** WIP)  
**Опора:** Ries (BML, innovation accounting) · Mom Test (обязательства ≠ комплименты) · Knapp (таймбокс) · Cagan (outcome)  
**Аудитория (гипотезы):** [`customer-stories-audience.md`](customer-stories-audience.md) — приоритет поиска: Артём · Юля · Марина · Саша / Ника  
**Не путать с:** правками шаблона для пользователей; это GTM самого Prod.Swaim.

---

## Северная звезда этого цикла

**Outcome:** подтверждённый спрос сегмента «основатель digital product / соло», который уже жёг время или деньги на оболочку (Notion kit / фрилансер / самосбор) и готов к **обязательству** (созвон с фактами прошлого, предоплата, внедрение среза).

**Не outcome:** охваты, лайки, «интересно», подписчики, клики без следующего шага с ценой.

### Innovation accounting (общие правила)

| Слой | Что считаем | Что игнорируем |
|------|-------------|----------------|
| Сильный сигнал | предоплата / оплата пилота; заполненные 2 раздела за 7 дней; intro к 2+ основателям; повторный визит к пространству | лайки, просмотры, «круто», сохранения без DM |
| Средний сигнал | созвон ≥20 мин с прошлым поведением (сколько платили/бросили); календарь; ответ на 3 конкретных вопроса про жизнь | общие «напишите если интересно» |
| Слабый | эмодзи-реакции, пересылки без текста | — |

**WIP:** параллельно не больше **одного** эксперимента из трёх. Остальные — бэклог.

**Kill / persevere:** решение в конце окна по таблице ниже, не по ощущению «было шумно».

## Эксперимент A — Outreach Mom Test → платный пилот

### Гипотеза

Верим, что основатели, которые **уже платили** за Notion OS / сборку у фрилансера и бросили, имеют боль «пустой kit». Если дать короткий разговор про *их* прошлое + узкий RU-срез Prod.Swaim с пилотной ценой, то ≥3 из 10 квалифицированных созвонов дадут предоплату или явный отказ с причиной (оба исхода — обучение).

### Для кого

Артём · Юля · Саша (кластер «оболочка / kit»).

### Build (минимум)

1. Список 30 контактов / ниш (TG-чаты основателей, Product Hunt RU-adjacent, личные intros) — без массового спама.
2. Скрипт outreach (не питч продукта): 4–5 строк про *их* последнюю попытку собрать OS; просьба о 20 мин.
3. Чеклист Mom Test на созвон + одностраничный оффер пилота (что входит / не входит / цена / срок 14 дней).
4. Публичная ссылка на Notion (read) + слот календаря.

### Measure (окно: 10 рабочих дней)

| Метрика | Цель (pass) | Fail / убить |
|---------|-------------|----------------|
| Исходящие с персонализацией | ≥25 | <15 за окно → канал мёртв или список плохой |
| Ответы с фактами прошлого (не «интересно») | ≥8 | <3 |
| Созвоны ≥20 мин | ≥5 | <2 |
| Предоплаты / оплаченные пилоты | ≥2 | 0 **и** нет чётких возражений «цена/срез/язык» → гипотеза сегмента слабая |
| Activation пилота: 2 раздела заполнены за 7 дней | ≥1 из оплативших | оплатили, но 0 activation → проблема onboarding, не канала |

### Learn (шаблон вывода)

- Что в прошлом болело сильнее: настройка / чужая ниша / нет must-have / ИИ без каркаса?
- За что реально готовы платить сейчас: доступ к шаблону / созвон-онбординг / оба?
- Pivot: сместить ICP / цену / формат пилота / канал поиска.

### Стоимость

~6–8 часов владельца (список + сообщения + 5 созвонов). Денег почти 0.

### Почему не vanity

Счётчик — обязательства и факты прошлого, не «охват поста».

## Эксперимент B — Community drop: боль → квалифицированный DM

### Гипотеза

Верим, что в 1–2 релевантных сообществах основателей пост **про брошенный Notion OS** (без «купите наш шаблон» в первом экране) с CTA «напишите в DM: сколько платили / на какой неделе бросили» отфильтрует ICP лучше рекламного креатива. Из квалифицированных DM ≥30% согласятся на созвон или пилот.

### Для кого

Тот же кластер + видимость для Марины (ложный сигнал) — в тексте можно задеть «все сказали круто».

### Build

1. Один черновик поста (RU), 1200–1800 знаков: история боли → 2 вопроса про прошлое → CTA в DM.
2. Правила: не втирать ссылку в первый комментарий сразу; ссылку/календарь — только после ответа с фактами.
3. Трекер: источник сообщества × качество DM (🔴🟡🟢 по Mom Test).
4. Запасной вариант CTA: короткая форма (3 поля: что пробовали / сколько потратили / бросили на неделе №) — только если DM запрещены правилами чата.

### Measure (окно: 7 дней после публикации × 2 сообщества)

| Метрика | Цель (pass) | Fail / убить |
|---------|-------------|----------------|
| Квалифицированные DM / формы (есть сумма или часы + факт броска) | ≥10 суммарно | <3 → канал/формулировка не тянет |
| Доля 🟢 среди ответов | ≥40% | всё 🔴 («звучит круто», без прошлого) → пост притягивает Игоря |
| Переходы к созвону / пилоту | ≥3 | 0 при ≥10 DM → оффер или следующий шаг сломан |
| Оплаты | бонус, не обязателен в B; достаточно сильных созвонов | — |

**Явно не KPI:** просмотры поста, реакции, репосты без текста.

### Learn

- Какое сообщество дало 🟢, какое — шум.
- Какие формулировки боли совпали с Артёмом/Юлей vs «пустой интерес».
- Нужен ли отдельный пост под «ложную валидацию» (Марина) или один кластер.

### Стоимость

~3–4 часа (текст + модерация DM + трекер). Риск: бан/удаление — читать правила чата.

### Почему lean

Один артефакт, два размещения, жёсткий фильтр ответа. Дешевле рекламы и честнее по сигналу.

## Эксперимент C — Concierge: 5 мест «сбор за 7 дней»

### Гипотеза

Верим, что узкий **платный** (или high-commitment) concierge — «за 7 дней вместе заполним Клиенты → Твой продукт → оффер» — сильнее голого доступа к Notion: люди платят за outcome, а мы узнаём, где шаблон тормозит activation. Цель: 5 мест, ≥3 оплаты (или эквивалент: предоплата / публичный commitment), ≥2 человека с заполненным foundation к дню 7.

### Для кого

Саша (вход) · Артём (уже платил) · Ника (нет нити сегмент→оффер). Не Игорь.

### Build

1. Лендинг-одностраничник или Notion-страница оффера: для кого / что будет на выходе / чего нет / цена / дедлайн набора.
2. Чеклист 7 дней (ежедневный микро-шаг ≤45 мин).
3. Канал связи (чат на 5 человек) + 1 групповой или 2 коротких check-in.
4. Критерий «готово»: три раздела заполнены своими словами, не демо-копипастой.

### Measure (окно: набор 7 дней + спринт 7 дней)

| Метрика | Цель (pass) | Fail / убить |
|---------|-------------|----------------|
| Заявки с прошлым поведением в форме | ≥8 | <3 |
| Оплаченные / предоплаченные места | ≥3 | 0 при ≥8 заявок → цена или обещание мимо; 0 заявок → сначала A/B |
| Activation day 7 (foundation 3 раздела) | ≥2 | оплаты есть, activation 0 → продукт/онбординг, не маркетинг |
| Удержание: вернулись на неделе 2 без пинга | ≥1 | все пропали → ценность среза под вопросом |

### Learn

- Платят ли за **сопровождение** сильнее, чем за файл?
- Какой шаг дня 1–3 бросают чаще всего → приоритет правок шаблона.
- Concierge масштабировать нельзя — это тест ценности, не канал роста. Если pass → упростить self-serve онбординг под те же шаги.

### Стоимость

Выше по времени владельца (~10–12 ч на спринт), зато самый плотный сигнал по ценности MVP-среза.

### Почему не vanity

Считаем оплаты и заполненные разделы, не «зарегистрировались на вебинар».

## Порядок запуска (рекомендация Growth)

| Порядок | Эксперимент | Зачем первым |
|---------|-------------|--------------|
| **1** | **A** Outreach → пилот | Самый дешёвый путь к Mom Test + деньгам; не зависит от модерации чатов |
| 2 | **B** Community drop | Если A дал язык боли — переносим формулировки в публичный пост |
| 3 | **C** Concierge | Если A/B дают интерес, но слабая activation — проверяем ценность среза руками |

Параллелить A+B допустимо только если владелец явно снимает WIP-лимит; C не параллелить ни с чем.

---

## Артефакты на выходе каждого эксперимента

1. Таблица строк: контакт → источник → сигнал 🔴🟡🟢 → следующий шаг → $ / отказ.  
2. 5–10 цитат **про прошлое** (не про нашу идею).  
3. Решение одной строкой: **persevere / pivot / kill** + что меняем в оффере или ICP.  
4. Если появилась оплата — зафиксировать в Финансах владельца; если дыра в шаблоне — отдельный issue на контент (не смешивать с этим GTM-тикетом).

---

## Вне скоупа SWA-6

- Дизайн полноценного лендинга и бренд-кампания.
- Платная реклама с оптимизацией на CTR/CPC.
- Правки модулей шаблона «на всякий случай» без сигнала из A–C.
- Vanity-дашборды (подписчики, impressions).
