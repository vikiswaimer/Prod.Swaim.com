## Как работаем дальше (важно)

> **Новый чат = одна группа** (и её блоки). Внутри чата — **диалог** с владельцем: гипотеза → правка → проверка ощущения / Notion → адаптация.

Жёсткая очередь пакетов E→J **снята**: большой сквозной план легко путает scope и провоцирует «додумывание» агентом. Владелец выбирает группу в новом чате; критерии и глубина подгоняются в разговоре, а не копируются слепо из черновиков ниже.

Правила процесса — в [`AGENTS.md`](../AGENTS.md) и [`agent-context.md`](agent-context.md).

**Что агенту не делать по этому файлу:**
- не открывать сразу issues E–J «по списку»;
- не тащить в чат чужие пакеты «заодно»;
- не считать чеклисты §3 обязательными без согласия владельца в текущем чате.

**Чем файл остаётся полезен:** память о foundation A–D / Other, карта возможных тем и старых критериев — если в диалоге захотите опереться.

## 3. Темы-подсказки (бывшие пакеты E–J)

Ниже — **идеи и черновые критерии**, не backlog к закрытию по порядку. В новом чате владелец называет **группу** (например «Клиенты» или «Активность / Идеи»); агент уточняет scope диалогом.

### Клиенты / сигнал (раньше «E»)

**Идея:** портрет через поведение и обязательства, не Age/Gender; связка с уже готовыми Отзывами и Интервью.  
**Черновик issue (опционально):** [`issue-drafts/pack-e-mom-test.md`](issue-drafts/pack-e-mom-test.md)

Возможные критерии (согласовать в чате):
- хаб `Бизнес/Клиенты--ee4c1042.md`;
- CSV портрета без persona-ядра;
- точечно поля Feedback, если ещё узкие;
- пример в `examples/`; чеклист Notion.

### Активность: идеи / задачи / цели / рефлексия (раньше «F»)

**Идея:** гипотеза, эксперимент, outcome, BML, WIP.  
**Черновик:** [`issue-drafts/pack-f-lean-activity.md`](issue-drafts/pack-f-lean-activity.md)

### Продукт / оффер / must-have (раньше «G»)

**Идея:** MVP = полезный (и по возможности платящий) срез; must-have не про логотип раньше ценности.  
**Черновик:** [`issue-drafts/pack-g-mvp-offer.md`](issue-drafts/pack-g-mvp-offer.md)

### Календарь / кампании как learning launches (раньше «H»)

**Идея:** таймбокс вопрос → прототип → тест.  
**Черновик:** [`issue-drafts/pack-h-sprint-launches.md`](issue-drafts/pack-h-sprint-launches.md)

### Позиционирование / конкуренты (раньше «I»)

**Идея:** outcomes, альтернативы и status quo, доказательства.  
**Черновик:** [`issue-drafts/pack-i-positioning-competitors.md`](issue-drafts/pack-i-positioning-competitors.md)

## 5. Issue в новом чате

Один чат → один issue под **выбранную группу** (не под «весь v2»).

Шаблон:

```text
## Цель
(группа + что хотим изменить)

## Диалог / гипотезы
(что проверяем с владельцем в этом чате)

## Методология
(Cagan / Ries / Mom Test / Sprint / Olsen — что уместно)

## Критерии готовности
- [ ] … (после согласования в диалоге)

## Файлы
- content/small-business-space-ru/…

## Перенос в Notion
…

## Вне скоупа
(другие группы)
```

Черновики E–J в `issue-drafts/` — **опциональные** заготовки текста, не обязательный порядок.
