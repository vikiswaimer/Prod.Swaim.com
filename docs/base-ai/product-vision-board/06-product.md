# Product

**Small Business Space v.1.0 [RU]** — Notion OS + Git-копия для агента/Obsidian.

## MVP-срез (Olsen)

- RU, ядро **Бизнес + Активность** + Instructions.
- Примеры отдельно от чистого шаблона.
- Методология: Cagan / Lean / Mom Test / Sprint.

## Модули v1

| Модуль | Роль в срезе |
|--------|--------------|
| Instructions | маршрут + ИИ-пара |
| Быстрый старт | Старт / Развитие |
| Бизнес | продукт, клиенты, оффер |
| Активность | задачи, идеи, цели, WIP |
| Other | интервью, доверие ✅ |

## UX-принцип

Hierarchy за 2 секунды: 00-index → трек → раздел. Пустые состояния с подсказкой «следующий шаг».
