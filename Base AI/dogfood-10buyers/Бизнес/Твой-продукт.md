# Твой продукт — Tool Map

## Часть 1. Ценность

- **Исход.** Человек за 15–30 минут видит карту инструментов своей ниши и 2–3 рабочие связки; при необходимости покупает подробный плейбук.
- **Гипотеза.** Верим, что сегмент тонет в выборе инструментов без картины связок; если дадим **map + платные подробные варианты**, то ≥10 оплат.
- **Минимальный полезный срез (MVP).**  
  Ниша `solo-digital-services` → интерактивная **map** (узлы = инструменты, рёбра = связки) → примеры в панели по клику → CTA на платный плейбук.  
  PostHog EU: `map_viewed`, `node_clicked`, `edge_clicked`, `paid_cta_clicked`.
- **Критерий успеха.** Оплаты детального слоя (цель 10) + использование map (события PostHog), не «лайки».
- **Главный риск.** Valuable: нужна ли map сильнее, чем очередной список; Viable: хватит ли маленькой цены.

## Часть 2. Формулировки

- **Название:** Tool Map  
- **Кратко:** карта цифровых инструментов по нише и примеры связок на схеме; подробные варианты — за небольшую плату.  
- **Ниша v0 (зафиксирована):** соло digital-услуги / инфобизнес.  
- **Срез:** `Base AI/dogfood-10buyers/map/` — 8 узлов, 8 связок, PostHog EU.  
- **Формат доставки MVP:** статическая web-map + CTA на платный плейбук.
