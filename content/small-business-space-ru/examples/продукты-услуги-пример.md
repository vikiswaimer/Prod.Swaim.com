Это **пример** (в т.ч. исторический прайс автора шаблона). В чистом шаблоне держите свои позиции. Рабочая страница: [Продукты / услуги](../Бизнес/Продукты%20Услуги--4bbcfa4e.md).

## Позиция: базовый срез пространства

| Поле | Пример |
|------|--------|
| Сегмент | Основатель цифрового продукта на старте / развитии |
| Проблема / исход | Не собирать OS с нуля; быстрее ясность продукта, клиента, оффера |
| Входит | Модули foundation + треки Старт/Развитие + работа без ИИ или с ИИ |
| Не входит | Полный кастом под нишу, ведение маркетинга за клиента |
| Цена (исторический ориентир автора) | от бесплатного среза знакомства до пакетов с настройкой (см. ниже) |
| Тип | Product / Service (настройка) |
| Статус | Для шаблона Prod.Swaim — живой продукт; для вашей копии — поставьте свой статус |

### Исторические строки автора (архив, не копировать слепо)

| Name | Price | Type |
|------|-------|------|
| Бесплатная ознакомительная | $0 | Product |
| v 1.0 | $30 | Product |
| v 1.0 - 1.2 | $199 | Product |
| с индивидуальной настройкой | $300 | Product |
| только индивидуальная настройка | $199 | Service |

Используйте как ориентир структуры прайса, не как «правильные» цены для вашего рынка.
