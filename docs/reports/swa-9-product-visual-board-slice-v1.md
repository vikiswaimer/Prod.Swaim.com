# SWA-9 — Product Visual Board: первый срез (UX)

**Дата:** 2026-08-18 · **Роль:** UX Designer  
**Статус:** lean-прототип v1 · **Не** переносить в пользовательский Notion без merge и теста

---

## Вопрос прототипа (один)

> **За ≤2 секунды** основатель понимает: **для кого** продукт, **какой срез** строит **сейчас**, **что проверяет** на этой неделе — без обхода 4–6 страниц?

Опора: Knapp (timebox, иерархия за 2 с) · Mom Test (не «красиво», а «понятно куда идти») · Olsen (MVP = полезный срез, не доска ради доски).

**Не проверяем в v1:** полный бэклог, релиз-таймлайн, конкурентную матрицу, свободные стикеры (анти-Miro).

---

## Решение UX

**Product Visual Board** — не canvas. Это **одна страница с 4 фиксированными зонами** (pattern: `Document` + callout-блоки Notion). Данные — ссылки/rollup из уже существующих полей «Для кого» и «Гипотезы» в [Продукт/_index.md](../../content/small-business-space-ru/Пространство-v2/Продукт/_index.md); дублировать длинные тексты нельзя.

### IA (иерархия сверху вниз)

| Зона | Смысл | Лимит | Пустое состояние |
|------|--------|-------|------------------|
| **A. Кому** | Сегмент + боль одной строкой | 1 карточка | «Выберите одну историю в Клиентах → ссылка сюда» |
| **B. Срез** | Минимальный полезный срез **сейчас** | 1 блок | «Заполните одну строку среза в Твой продукт / Для кого» |
| **C. Проверка** | **Одна** гипотеза в работе + сигнал успеха | WIP=1 визуально | «Добавьте одну строку в Гипотезы со статусом „сейчас“» |
| **D. Шаг** | Одно действие сегодня (deep link) | 1 CTA | «Откройте Сейчас → Сегодня» |

```text
┌─────────────────────────────────────────────────────────┐
│  A. КОМУ          │  B. СРЕЗ (сейчас)                      │
│  [1 сегмент]      │  [1 outcome / срез]                    │
├───────────────────┴────────────────────────────────────────┤
│  C. ПРОВЕРКА (1 гипотеза)     │  сигнал: …                  │
├─────────────────────────────────────────────────────────────┤
│  D. → Одно действие сегодня: [ссылка]                       │
└─────────────────────────────────────────────────────────────┘
```

### Поток (happy path)

1. Открыть **Продукт → Product Visual Board** (или закрепить как landing группы «Продукт» в v2).
2. Прочитать 4 зоны ≤10 с.
3. Клик по **D** → страница «Сейчас / Сегодня» или «Гипотезы» для правки.
4. Вернуться — зона C обновлена (ручной sync в v1; rollup — v2 impl).

### Антипаттерны (отказываем)

- Свободная доска / infinite canvas (проигрываем Miro; боль Саши «пустая доска»).
- Больше одной гипотезы «сейчас» на экране (ломает WIP=1).
- Ссылка на GitHub / internal docs в теле board.
- «Заполните все разделы» — только **один** следующий шаг в D.

## AC (проверяемые)

- [ ] **AC1:** На прототипе видны ровно 4 зоны A–D; нет пятой «на всякий случай».
- [ ] **AC2:** Заголовок + зоны A+B читаются за **≤2 с** (5-секундный тест с 1 респондентом: «для кого и что строите?»).
- [ ] **AC3:** В зоне C не больше **1** гипотезы со статусом «сейчас»; вторую — только в linked table «Гипотезы», не на board.
- [ ] **AC4:** Зона D ведёт на **одну** существующую страницу типа `Activity` / «Сегодня» — не на INDEX.
- [ ] **AC5:** Пустые состояния A–D содержат **одно** действие каждое, не список из 5 ссылок.
- [ ] **AC6:** Нет internal/agent ссылок в пользовательском тексте.

## Как узнаем, что срез сработал

| Метод | Порог | Срок |
|-------|-------|------|
| 5-секундный тест (1 основатель, не команда) | ≥4/5: называет сегмент + срез без подсказок | 1 сессия после impl |
| Mom Test follow-up | «Открывали бы эту страницу в начале недели?» — прошлое поведение, не «понравилось» | внутри W1 интервью |
| Отказ | Респондент просит «вернуть список всех баз» → board слишком пустой или не туда ведёт D | stop / pivot |

**Сигнал успеха v1:** человек **сам** закрепляет board или открывает его 2+ раза за неделю без напоминания.

## Handoff → FoundingEngineer

**Pattern names:** `Document` hub · 4× `callout` / column layout · deep link CTA · empty state one-liner · (v2) rollup из DB «Гипотезы».

**Scope impl v1 (Notion):**

1. Страница по markdown-прототипу в группе «Продукт» (Пространство v2).
2. 2-column Notion layout: A|B, full-width C, full-width D.
3. Manual sync OK; авт rollup — **не** блокер v1.
4. **Скриншот** rendered UI в PR — без него board возвращается UX.

**Не в v1:** board view, gallery, формулы, sync с v1 SBS «Бизнес».

**Copy/offer:** GrowthMarketer не трогаем; иерархия и trust — UX.
