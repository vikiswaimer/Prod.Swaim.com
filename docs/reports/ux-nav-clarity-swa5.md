# Отчёт: UX-навигация 00-index / Быстрый старт (SWA-5)

Дата: 2026-08-15 · Ветка: `cursor/ux-nav-clarity-1a8e`  
Роль: UX Designer · критерий: **ясность ценности за 30 секунд**

## Вердикт

Ядро (два трека + foundation) уже сильное. Слабое место — **домашняя**: после value prop все модули выглядели равноправными «делами», CSV и INDEX конкурировали с выбором трека. За 30 секунд человек понимал «что это», но не **что сделать сейчас**.

## Аудит (до)

| Сигнал | Проблема |
|--------|----------|
| Первый экран | Три ссылки (Instructions / INDEX / пример) рядом с треками → нет одного главного CTA |
| Карта модулей | Полные списки + CSV + «Подробнее в INDEX» в каждом блоке → ощущение «надо заполнить всё» |
| Жаргон | «Foundation» в таблице выбора без пояснения на русском |
| Библиотека / маркетинг-операции | На одном уровне с Бизнесом → уход в сайдбар вместо Клиентов / Твой продукт |
| Треки | Критерии выбора хорошие; не хватало **одного действия на сегодня** в шапке |
| INDEX | Порядок треков: Развитие выше Старта |

Стыкуется с холодным аудитом (#33): типичный провал — сайдбар → Библиотека / планировщик соцсетей → бросил, не тронув foundation.

## Гипотеза правки

Если домашняя **сначала** заставляет выбрать трек и явно понижает карту разделов до ориентира (не todo), а в шапке трека даёт «сегодня: 1–2 ссылки», то за 30 секунд яснее: *что это → куда я → что открыть сейчас*.

## Notion — перенести вручную

1. Корневая страница пространства = текст `00-index.md` (callout «за 30 секунд» + таблица треков + сжатая карта).
2. Шапки двух страниц треков — абзац «Сегодня».
3. Instructions → блок «С чего начать».
4. В Notion sidebar по возможности: Быстрый старт выше Библиотеки; Библиотеку не держать «первой после дома».

## Критерий готовности (проверка)
