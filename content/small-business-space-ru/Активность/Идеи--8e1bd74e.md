# Гипотезы

Это база **проверяемых гипотез**, а не склад «классных идей». Сюда попадает только то, что можно сформулировать, протестировать и закрыть выводом: подтверждена / опровергнута / уточнить.

Мысль без способа проверки и сигнала успеха сюда не кладут — или сразу дописывают до формулы, или оставляют в личном inbox.

<aside>
Формулировки и статусы живут здесь (Notion). Исполнение эксперимента — лучше в Linear или GitHub Issues. В карточке держите ссылку на issue.
</aside>

---

## Зачем это в шаблоне продукта

1. **Не путать желание с гипотезой** — «сделаем фичу» ≠ «верим, что изменится поведение».
2. **Ограничить WIP обучения** — в проверке одновременно 1–3 гипотезы.
3. **Закрыть цикл Lean:** гипотеза → дешёвый тест → вывод → next step.

Исход раздела: вы всегда можете назвать, какие гипотезы сейчас в работе и что будет считаться успехом или провалом.

В Notion страницу базы можно назвать **Гипотезы** (вместо старого «Идеи»).

---

## Как устроен поток

```text
Черновик формулы → уточнить (факты) → к проверке → в работе (эксперимент)
                                                    ↓
                                          вывод → next step
                                          или отложить / отбросить
```

| Статус | Смысл |
|--------|--------|
| Черновик | Есть тема, формула ещё неполная |
| Уточнить | Нужны факты / интервью до теста |
| К проверке | Формула и способ проверки ясны; ждёт слота WIP |
| В работе | Идёт эксперимент (есть задача / issue) |
| Вывод | Обучение зафиксировано: подтверждена / опровергнута / уточнить |
| Отложена | Не сейчас; причина коротко |
| Отброшена | Явно нет — чтобы не всплывала снова |

«К проверке / В работе / Вывод» ≈ To learn / Doing / Learned.

## Формула

Кратко в карточке:

> Верим, что **[кто]** сталкивается с **[проблемой]**.  
> Если дадим **[решение / срез]**, то **[поведение или метрика]** за **[срок]**.

Плохо: «Сделаем тёмную тему — всем понравится».  
Лучше: «Верим, что фрилансеры бросают онбординг из‑за длинной формы. Если сократим до 3 полей, активация за 7 дней вырастет с 20% до 35%».

Разговор с рынком — про **их жизнь и прошлое**, не «купили бы вы…» (см. Интервью / Отзывы в Дополнительно).

## Поля карточки (минимум)

| Поле | Смысл |
|------|--------|
| Название | Короткий ярлык гипотезы |
| Формулировка | Полная формула выше |
| Как проверим | Самый дешёвый честный тест за N дней |
| Сигнал успеха | Метрика, поведение, обязательство |
| Статус | Из таблицы выше |
| Вывод | Что узнали + вердикт |
| Next step | Что делаем после вывода |
| Ссылка наружу | Issue в Linear / GitHub |
| Доверие / Выполняемость / Влияние | Вторичный приоритезатор; не замена формулы |
| Баллы | Ориентир порядка; высокий балл ≠ «делать сразу» |

## Где вести проверку

| Место | Роль |
|-------|------|
| **Эта база (Notion)** | Формулировки, приоритет, статусы, выводы |
| **Linear** | Исполнение с ИИ: циклы, статусы, чистый WIP |
| **GitHub Issues** | Если работа уже в репозитории; issue = эксперимент |
| [Задачи](Задачи--c110a4ad.md) здесь | Лёгкий WIP без отдельного трекера |

Правило: **одна карточка-истина здесь + одно место исполнения**.
