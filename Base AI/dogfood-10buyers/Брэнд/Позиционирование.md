# Позиционирование — Tool Map

**Для кого (портрет):** фаундеры и предприниматели (соло / микрокоманда).  
**Ниши:** тестируем и меняем по сигналу (сейчас: соло digital-услуги / инфобизнес).  
**Работа:** карта инструментов и связок; детали — за небольшую плату.  
**Не является:** полный SaaS directory, курс на 40 часов, консалтинг, Prod.Swaim kit.  
**Доказательство:** PostHog (map) + оплаты плейбуков + keep/kill ниш в портфеле.
