## Outcome цикла

≥5 созвонов ≥20 мин с людьми, у которых есть **прошлое** про оболочку продукта (kit / Notion / фрилансер / самосбор), и хотя бы один из исходов:

- ≥1–2 **pre-order / предоплата / intro** с причиной, **или**
- ≥3 карточки с суммой + неделей броска + workaround (даже без оплаты), **или**
- явный **отказ с причиной** (тоже Learn).

После цикла — патч светофора H1/H4/H5 в risk-map (#34) и evidence pack (#37).

**Не outcome:** лайки, «круто», «интересно», новые страницы шаблона.

## Кластер (WIP=1)

Только **«уже платили / жгли время на оболочку и бросили»** (+ 1–2 разговора «ложный сигнал», если сами выходят).

| В приоритете | Не звать сейчас |
|--------------|-----------------|
| Паттерн Артём · Юля · Катя | Игорь (интерес без обязательств) |
| Саша — только если есть часы на самосбор | «Все 18 ракурсов» |
| Марина — после 3+ kit-разговоров | Дима/Learn — после valuable |

## Build (чеклист до первого созвона)

1. **Список 25–30** контактов / ниш (TG, intros, бывшие клиенты CEO) — без спама.
2. **Outreach (4–5 строк, не питч):**
   - спросить про *их* последнюю попытку навести порядок в продукте/клиентах;
   - попросить 20 мин;
   - без «купите Prod.Swaim» в первом сообщении.
3. **Календарь** + запись заметок (один шаблон карточки ниже).
4. **Оффер пилота** — на столе *после* фактов прошлого (что входит / не входит / цена / 14 дней). Можно взять каркас из growth A (#38).
5. Публичная read-only ссылка на Notion — только по запросу после созвона или как follow-up.

---

## Скрипт созвона (только прошлое)

Порядок важен: сначала жизнь человека, потом (опционально) наш срез.

1. Когда в последний раз пытались навести порядок в продукте / клиентах / задачах? Сколько часов?
2. Что уже пробовали (Notion с нуля, чужой шаблон, фрилансер, ИИ, Excel)? Что бросили и на какой неделе?
3. Сколько денег уже отдали за похожую работу? Что получили взамен?
4. После «круто» от кого-то — что человек **сделал** за 7 дней?
5. Кого из «почти клиентов» сознательно отшили — почему?
6. (Поздний слот) Если уместно: готовы ли intro / предоплата на узкий пилот — **да/нет + причина**.

Запрещено как ядро: «купили бы?», «интересно ли наше X?», демо-питч на полсозвона.

## Measure (окно ~10 рабочих дней)

| Метрика | Pass | Fail |
|---------|------|------|
| Исходящие с персонализацией | ≥25 | <15 |
| Ответы с фактами прошлого | ≥8 | <3 |
| Созвоны ≥20 мин | ≥5 | <2 |
| Pre-order / оплата / intro | ≥1–2 (или отказы с причиной) | 0 фактов и 0 отказов с причиной |
| Карточки только «круто» | 0 в отчёте | если >50% карточек 🔴 — убить формулировку outreach |
